# 💰 Smart Expense Tracker & Budget Monitoring System

A web-based application developed using **ASP.NET, C#, and CSS** that helps users efficiently **track expenses, manage budgets, monitor savings goals, and analyze financial health** in a smart and user-friendly way.
---
## 📌 Project Overview

Managing daily expenses and budgets manually is time-consuming and error-prone.  
This system provides a **smart, digital solution** to track income, expenses, budgets, savings, and financial health — all in one place.

It allows users to:
- Record daily expenses  
- Track income  
- Manage budgets  
- Monitor financial goals  
- Analyze spending patterns  

---

## 🚀 Features

- 🔐 Secure User Authentication (Login & Registration)
- 💸 Expense Tracking
- 📊 Budget Monitoring
- 💰 Income Management
- 🎯 Savings Goal Tracking
- 📈 Financial Health Dashboard
- 🕒 Login History Tracking
- 📱 Responsive UI Design
